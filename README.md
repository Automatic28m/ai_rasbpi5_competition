## 📜 กติกาการแข่งขัน

### Section 1 : พัฒนาโมเดลปัญญาประดิษฐ์เรียนรู้เชิงลึก (Deep learning)
1. พัฒนาโมเดลจาก dataset ที่กำหนดให้:
   - Video Dataset ความยาว 3 นาที
   - Video Validate ความยาว 30 วินาที
   - Video Test ความยาว 10 วินาที
2. ข้อมูล dataset จะทำการเก็บข้อมูลพร้อมกันทุกทีมในวันแข่งขัน
3. พัฒนาโมเดลด้วยอัลกอริทึม **YOLO26** เท่านั้น
4. ใช้โปรแกรม Label Studio แบบ Offline ในการทำ Labeling รูปภาพ
5. โมเดลที่พัฒนาขึ้นจะต้องสามารถตรวจจับวัตถุแบบ real-time ได้
6. พัฒนาโปรแกรมด้วยภาษาไพธอน (Python) และใช้ Python Environment ที่กำหนดให้ (เช่น Pytorch, Ultralytics, ONNX Runtime, pillow, opencv, numpy, matplotlib, math ฯลฯ)
7. 🚫 **ไม่อนุญาต** `pip install` Package ใด ๆ ในวันแข่งขัน
8. 🚫 **ไม่อนุญาต** ให้นำ USB หรืออุปกรณ์เก็บข้อมูลอื่น ๆ เข้ามาใช้
9. 🚫 **ไม่อนุญาต** ให้ใช้ AI Assist, Auto Code, Auto Label
10. ให้ใช้เครื่องคอมพิวเตอร์ที่กำหนดให้เท่านั้น

### Section 2 : พัฒนาโมเดลปัญญาประดิษฐ์สำหรับอุปกรณ์ Raspberry Pi 5
1. ทำการ Fine-tune และแปลงโมเดล (Yolo) ให้เป็นรูปแบบ **.onnx** เพื่อประมวลผลบน Raspberry Pi 5
2. ใช้ Raspberry Pi OS Image และ Python Environment ที่กำหนดให้เท่านั้น (ติดตั้ง package ที่จำเป็นไว้ให้แล้ว)
3. Config อุปกรณ์ Raspberry Pi 5 เพื่อให้สามารถประมวลผลโมเดลได้
4. ทดสอบโมเดลด้วย Video File ที่กำหนด
5. แสดงผลการทดสอบแบบ Real-time บนอุปกรณ์ Raspberry Pi 5

## 🏆 เกณฑ์การให้คะแนน

**1. ความแม่นยำของโมเดล (70%)**
- กำหนดให้ค่า Confident Threshold ต้องสูงกว่า 0.4
- **สูตรคำนวณ:** `((จำนวน Object ที่ตรวจพบจริง - จำนวน Object ที่ตรวจพบผิดพลาด) / จำนวน Object ที่ต้องการทั้งหมด) x 70%`

**2. ความเร็วในการประมวลผลเฉลี่ย (30%)**
- คิดจาก Frames per second (FPS) ที่ประมวลผลบน Raspberry Pi
- **สูตรคำนวณ:** `(ค่า FPS ที่วัดได้จาก Raspberry Pi / ค่า FPS ของ Video Test) x 30%`

*หมายเหตุ: หากมีทีมที่ได้คะแนนเท่ากัน*
1. ตัดสินผู้ชนะจากทีมที่มีขนาดไฟล์โมเดล `.onnx` ที่น้อยกว่าเป็นอันดับแรก
2. หากขนาดไฟล์เท่ากัน จะตัดสินจากทีมที่ส่งผลการแข่งขันก่อน
